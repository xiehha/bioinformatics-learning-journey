# Week 01: Python Basics

## 项目简介
这是我在生物信息学实践计划中的第一周练习，本仓库包含了 Python 基础语法的练习代码，以及基于模拟 OD600 数据的计算脚本。

## 文件夹结构
- `data/`: 存放实验练习数据 (如 OD600 数据表)。
- `scripts/`: 存放本周编写的 Python 脚本。
- `notes.md`: 个人的学习笔记。

## 运行环境
- 操作系统: Windows
- 环境管理: Miniconda (环境名: `bioenv`)
- Python 版本: 3.10.22
- IDE: VS Code

## 脚本说明 (scripts/)
- `hello.py`: 环境测试脚本。
- `variables.py`: 变量与基础数据类型练习。
- `od600_average.py`: 列表操作与均值计算。
- `input_experiment.py`: 标准输入与格式化输出练习。
- `unit_conversion.py`: 质量单位换算程序。
- `experiment_calculation.py`: 稀释倍数计算程序。
- `od600_average2.py`:列表操作与均值计算，input输入列表。
- `list_practice.py`:列表操作练习。
